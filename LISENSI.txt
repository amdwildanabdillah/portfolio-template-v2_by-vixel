======================================================
LISENSI PENGGUNAAN TEMPLATE VIXEL CREATIVE (OPEN SOURCE)
======================================================

Terima kasih telah menggunakan template portofolio digital dari Vixel Creative!

Template versi ini dirilis dengan semangat Open Source. Agar sama-sama nyaman, berikut adalah aturan mainnya:

1. BEBAS DIGUNAKAN & DIMODIFIKASI
Kamu bebas mengedit isi, warna, gambar, dan tata letak untuk keperluan portofolio atau website pribadimu sendiri maupun untuk klien/orang lain.

2. BEBAS DIDISTRIBUSIKAN
Berbeda dengan lisensi V1 kami, pada versi ini kamu diizinkan mengunggah, membagikan, atau menyebarkan file source code ini ke forum publik, grup, atau repositori terbuka (seperti GitHub) secara gratis.

3. TIDAK UNTUK DIJUAL ULANG (RESELL) SECARA MENTAH
Dilarang keras memperjualbelikan (resell) source code template ini dalam bentuk file aslinya ke pihak manapun. Kamu hanya diperbolehkan mengenakan tarif atas "jasa modifikasi", "jasa instalasi", atau "jasa pembuatan web", bukan menjual source code murni dari Vixel Creative.

4. HAK CIPTA & KREDIT
Struktur kode dan desain awal adalah hak cipta Vixel Creative. Kami sangat mengapresiasi jika kamu membiarkan teks kredit "Template by Vixel Creative" (jika ada), namun untuk keperluan profesional branding-mu, kamu diperbolehkan menghapusnya.

Sukses selalu untuk karir dan karyamu!
